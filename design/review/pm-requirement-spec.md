## 1. 一句话定义

PalmEnsemble 是一台面向零乐理用户的中文空间八拍循环乐器：用户把八颗带颜色、图标和试听反馈的鼓点/和弦旋律球放入中央 8 格轨道，在固定 100 BPM 下由扫描光逐格触发，并能在不中断当前小节的前提下继续替换或移走音色。

## 2. 用户与场景

- 目标用户：没有乐理或 DAW 经验、希望一分钟内得到好听节奏的 PICO 用户。
- 使用场景：客厅或空旷室内，站立或坐姿，单人，5–15 分钟轻量创作。
- 核心任务：一键示例入门；抓球、试听、吸附入格；播放/暂停；播放中无断拍修改；清空；记录最多 30 秒并保存本地事件序列。
- 关键决策：选择氛围；选择音色；选择节拍格；决定保留或移除当前小节中的声部。
- 风险不使用未经验证的单一“低”标签，改用 §7 的 likelihood × severity 风险登记；舒适、可达性与音频时序在实机验证前保持开放。
- 空间必要性初判：方向（左右音色家族）、位置（8 格节拍）、身体动作（抓放）和时间扫描被统一成一件可理解的空间乐器；2D 可实现功能，但不能同样直接地表达“拿起声音放进时间”。

## 3. 关键时刻

- 屏幕难以替代的瞬间：用户从左侧拿起“底鼓球”，放入第三格；球吸附、试听并在下一小节生效，扫描光经过时球体发亮且声音同步出现。
- 沉浸层级：核心体验为 Full Space / Stage；控制信息附着在中央乐器附近，不新增独立窗口。
- 入口：启动后以简短中文“开始演示”引导进入 Stage；示例节奏可一键加载。

## 4. 冻结意图

- 领域：休闲音乐创作 / step sequencer / 空间乐器。
- 默认空间：Full Space Stage。
- 固定约束：8 steps、100 BPM、8 种内置合成或免版权音色、3 个预设氛围、下一小节量化变更、无缝循环。
- 时间术语：`beat` 为四分音符，100 BPM 下 600ms；`step` 为八分音符，300ms；`bar` 为 4/4 的一小节、共 8 steps、2400ms；step index 为 0..7；bar boundary 是从 step 7 回到 step 0 的单调时钟瞬间。本文口语“八拍”一律指“八格单小节循环”，不指八个四分音符拍。
- 输入：手柄必须完整覆盖选择、放置、移除、播放控制；直接手势是可选增强，不能成为唯一入口。
- 数据：本地序列、预设、录制事件和时间戳；不联网、不导入歌曲、不接版权曲库。
- AI：无自动作曲或生成式功能。
- 权限：首版不依赖麦克风；保存到应用私有存储。若未来启用系统音频录制，另行验证 API 与权限。
- 协作：无多人、无联网分享。

## 5. 假设清单

| # | 假设 | 置信度 | 影响 | 验证计划 |
|---|---|---|---|---|
| 1 | 每格允许鼓和旋律各一个槽位，最多同拍双触发 | 中 | 决定轨道数据结构和视觉堆叠 | 用 5 名零基础用户观察是否能理解双层格 |
| 2 | 30 秒“录制”首版保存演奏事件 JSON，不声称导出音频 | 高 | 限定存储与 UI 文案 | 构建时标注“事件记录”，设备 API 明确后再评估音频捕获 |
| 3 | 音频资源可用 Android SoundPool 加载应用内原创合成 WAV | 中 | 决定低延迟与循环稳定性 | 实机测首触发延迟、连续 20 圈漂移和爆音 |
| 4 | 用户可用扳机抓取、摇杆/指向移动、松开吸附，A 键播放 | 中 | 手柄映射影响可达性 | 实机手柄测试并保留面板按钮等价入口 |
| 5 | 坐姿和站姿都以用户前方约 1.2–1.8m 的舒适区展示 | 中 | 决定初始 Stage 布局 | PICO 设备校准后验证可达范围与遮挡 |

## 6. 需求边界

明确不做：专业 DAW、歌曲导入、自动作曲、复杂混音、在线音色/版权曲库、联网分享、可变 BPM、多小节编曲、钢琴卷帘和效果器链。

## 7. 质量合同

- 必达结果：新用户可一键示例或通过抓放在 60 秒内听到节奏；8-step 以固定 100 BPM 无缝循环；播放中增删改只在下一小节统一提交；手柄可完成所有主任务；录制最多 30 秒并明确保存本地事件序列。
- 效率标准：首个球放置不超过 3 次操作；播放/暂停一步可达；清空需要二次确认；pending 修改状态一眼可见。
- 不得失败：不可在小节中途改变发声 pattern；不可因为替换声音截断当前正在发声的短音；扫描视觉与音频 step 不得明显错位；不可把事件保存描述成音频录制。
- 默认可见主窗口：Stage-only，0 个常驻 WindowContainer；控制面板作为 Stage AttachmentPanel 附着于轨道下方。
- 领域组件深度：节拍格必须呈现当前/待提交/扫描/空四类状态；音色球必须呈现家族、名称、图标、颜色、试听和已放置状态。
- 数据可信：显示固定 `100 BPM`、当前氛围、录制剩余秒数和保存类型；本地保存失败要给中文恢复提示。
- 平台约束：单一 Full Space Stage；右手米制；交互实体具备 Collision + Interactable；手柄输入是完整路径；Compose 仅使用 SpatialUI + PicoTheme。
- 原创性：吸收竞品的即时入门、量化和多通道反馈，但以“可抓取声音球 + 一维八格时间轨”取代多轨 DAW、采样器和 8×8 clip 网格。
- 验收计划：领域单元测试覆盖边界提交和循环；Gradle 构建；设计样式验证；PICO 设备或模拟器验证启动、手柄、音频和截图；实机不可用时必须明确缺口。

### 风险登记

定性量表：可能性 `低`=本轮 5 人测试预计 0–1 人触发，`中`=2–3 人，`高`=4–5 人或必现；严重性 `低`=可自行恢复且不影响完成，`中`=需主持人提示/重试或造成节奏中断，`高`=不适、安全、数据丢失或无法完成。矩阵优先级：高严重性一律 P1；中严重性×中/高可能性为 P1；中严重性×低可能性或低严重性×高可能性为 P2；其余 P3。P1 立即停止相关任务并修补后复测，P2 进入首版前修补，P3 记录并在下一轮观察。

| 风险 | 可能性 | 严重性 | 证据状态 | 缓解 | 关闭条件 |
|---|---|---|---|---|---|
| 播放中修改产生断拍 | 中 | 高 | 需求明确、实现未证 | immutable active pattern + boundary swap | 单测和 20 圈运行均无中途提交 |
| 控制器射线/抓放不可达 | 中 | 中 | 设备证据缺口 | 大碰撞体、吸附容差、按钮等价路径 | 坐/站各 5 次无协助完成 |
| 扫描高亮造成视觉疲劳 | 中 | 中 | 设备证据缺口；按保守等级归为 P1 | 禁止全屏闪烁、Reduce Motion | 10 分钟测试无 P1 不适报告 |
| 音频首触发延迟或断音 | 中 | 高 | API 与设备待测 | 预载、音频池、调度前视 | 首触发与连续 20 圈通过 |
| 用户误以为事件记录是音频 | 中 | 中 | 文案风险 | 始终标注“事件序列（非音频）” | 5/5 用户能复述保存内容 |

### 新手形成性测试协议

- 招募：5 名从未使用 DAW/step sequencer 的参与者；允许有基础 XR 经验，但其中至少 2 名 XR 新手；坐姿和站姿都覆盖。
- Task A 演示：从冷启动到加载示例并播放；计时起点为画面可交互，终点为用户口头指出扫描会循环。
- Task B 独立创作：清空后仅凭界面放入至少 1 个鼓点和 1 个旋律球，并播放一整圈；示例不得计入独立创作成功。
- Task C 量化理解：播放中替换一个球，询问“什么时候会听到变化”；必须回答“下一圈/下一小节”并在边界听到。
- 操作计数：一次扳机按下→移动→松开算一次抓放尝试；播放按钮一次激活算一步；系统自动吸附不额外计数。
- 通过阈值：5/5 在 60 秒内完成 Task A；至少 4/5 在 60 秒内完成 Task B；5/5 完成 Task C；每人控制器误放不超过 2 次且可自行恢复。
- 舒适与升级：任何明显眩晕、持续眼疲劳或不可达均为 P1，停止测试并调整距离/亮度/输入容差后复测。

## 8. 需求追踪

| 需求 | 实现节点 | 验证 |
|---|---|---|
| 8-step sequencer / 100 BPM | `SequencerClock`, `Pattern`, 4/4 八分音符网格 | 单测 step=300ms、bar=2400ms、8 步回环 |
| 下一小节量化生效 | `pendingPattern` → bar boundary commit | 单测第 1–7 步不提交、第 0 步原子提交 |
| 抓放吸附 | 球实体、格碰撞体、`SnapToStepUseCase` | 单测最近合法格与越界回弹；设备拖放 |
| 无缝循环 | 单调时钟调度 + SoundPool 预载 | 20 圈日志与听感测试 |
| 三氛围/八音色 | `SoundCatalog`, preset 映射 | 配置测试与 UI 枚举 |
| 开始演示/示例 | onboarding panel + example pattern | 新手任务测试 |
| 手柄完整控制 | ray select/grab/drop + 播放快捷键 | PICO 手柄验收 |
| 清空 | 二次确认后写 pending clear | 播放中清空于下小节生效测试 |
| 30 秒保存骨架 | `EventRecordingRepository` JSON | 30 秒自动停止、文件可读测试 |
| 截图两态 | 编辑态、播放扫描态 | 模拟器/设备截图文件 |
